# Org messaging style guide (seed for Memento)

The organisation's voice. Loaded into memory so every module sounds the same.
The team can edit it.

- **Tone:** friendly, practical, never blaming. "We all get tricked sometimes."
- **Reading level:** plain English, short sentences, no unexplained jargon.
- **Structure:** hook → what's happening → how to spot it (3–5 red flags) → what to do → how to report.
- **Call to action:** always end with how to report (e.g. "Forward to security@company.example" or use the Report Phish button).
- **Length:** tip ≤ 120 words; newsletter ≤ 500 words; quiz = 5 MCQs with explanations.
- **Citations:** every factual claim cites a trusted source from `config/sources.yaml`.
- **Never:** fear-mongering, shaming named people or teams, real employee data, live malicious links.
- **Phishing simulations:** always clearly marked as TRAINING in metadata; use only reserved domains (`example.com`, `example.org`).
